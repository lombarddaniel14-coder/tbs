A local voice assistant. Wake word, British voice, and real tools that read
your actual machine and your actual files. Runs on your PC; the only thing
that leaves it is the text of what you say.

-------------------------------------------------------------------------------
  3. WHAT'S MISSING  (two keys)
-------------------------------------------------------------------------------

KEY 1 - ANTHROPIC_API_KEY   (required - this is his brain)

  1. Go to console.anthropic.com
  2. Sign in. Add billing (pay-as-you-go, separate from any Claude subscription).
  3. Settings -> API Keys -> Create Key. Name it "TBS".
  4. COPY IT NOW. It is shown exactly once and never again.
  5. In PowerShell:

         setx ANTHROPIC_API_KEY "sk-ant-your-key-here"

  6. OPEN A NEW POWERSHELL WINDOW.
     setx does NOT affect the window you typed it in. This is the single most
     common reason it appears to fail. Close it, open a fresh one.

  7. Verify:

         $env:ANTHROPIC_API_KEY

     If it prints your key, done.

  Alternative: create a file named  .env  in the TBS root containing:
         ANTHROPIC_API_KEY=sk-ant-...


KEY 2 - PICOVOICE_ACCESS_KEY   (optional - this is his ears)

  Free, no credit card. Only needed for the "TBS" wake word.
  Without it he still works - you just type instead of speak.

  1. console.picovoice.ai -> sign up -> copy the AccessKey
  2. setx PICOVOICE_ACCESS_KEY "your-key-here"
  3. py -3.11 -m pip install pvporcupine

  Note: "TBS" is a built-in wake word. No training, no custom model.

  4. HOW TO RUN HIM
-------------------------------------------------------------------------------

    cd "<VAULT_ROOT>\Projects\Tools\TBS\core"

    py -3.11 main.py --text          Keyboard only. No mic needed. Start here.
    py -3.11 main.py                 Voice if available, keyboard if not.
    py -3.11 main.py --once "..."    One question, then exit.

  Check the voice stack at any time:
    cd ..\personality
    py -3.11 voice.py --check

-------------------------------------------------------------------------------
  7. CHANGING HIS PERSONALITY
-------------------------------------------------------------------------------

  Open  personality\system-prompt.md  and edit the prose. That's it - no code.

  It is parsed at runtime, so the next time you start him, he has changed.

  The rules that make him feel like TBS:
    - Always "sir"
    - Two sentences max when speaking
    - Dry pushback ONCE, then comply
    - Never fabricate - "I don't have that, sir"
    - No filler openers ("Certainly", "Great question")
    - Reads your files before answering about your projects; never guesses


-------------------------------------------------------------------------------
  8. WHEN SOMETHING BREAKS
-------------------------------------------------------------------------------

  "No module named X"
      cd core         &&  py -3.11 -m pip install -r requirements.txt
      cd personality  &&  py -3.11 -m pip install -r requirements.txt

  "My API key was rejected, Sir"
      The key is wrong, expired, or has no billing. Check console.anthropic.com.

  Key set but he still says it's missing
      You didn't open a new terminal after setx. Close it. Open a fresh one.

  No sound
      py -3.11 voice.py --check     (confirms Piper + the voice model)
      Then check Windows output device - is it routed somewhere unexpected?

  He doesn't hear the wake word
      PICOVOICE_ACCESS_KEY missing, or pvporcupine not installed. See section 3.

  His project info is stale
      Double-click "Refresh TBS Index.bat"

  'py' is not recognized
      Python 3.11+ isn't installed or isn't on PATH. Reinstall from python.org
      and tick "Add python.exe to PATH".


-------------------------------------------------------------------------------
  9. PRIVACY - what leaves this machine
-------------------------------------------------------------------------------

  STAYS LOCAL:  your voice audio, wake-word detection, transcription,
                speech synthesis, all file reads, all system info

  LEAVES:       only the TEXT of what you said, plus context (date, your
                remembered facts, today's schedule), sent to the Claude API

  Your actual voice recording never goes anywhere.
